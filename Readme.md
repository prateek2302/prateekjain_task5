# Laundry Services - CSS Hero Section

A responsive hero landing page created for the TuteDude MERN Stack assignment.

## Features
- **Pure CSS Layout**: Built strictly using `inline-block`, vertical alignment, and viewport units (`vw`, `vh`) without Flexbox or CSS Grid.
- **Full Viewport Sizing**: Designed to fit seamlessly in 100vh without vertical page scroll.
- **Clean Structure**: Semantic HTML5 elements (`header`, `main`, `nav`).

## Files Included
- `index.html` - Structure of the navbar and two-column hero section.
- `style.css` - Styling rules, typography, and viewport positioning.
- `Readme.md` - Documentation and project details.
